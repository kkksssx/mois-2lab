# Платформа для проведения онлайн-конференций и вебинаров

Лабораторная работа №2 «Реализация объектной модели» (курс «Объектное моделирование
интеллектуальных систем»). Оконное приложение на Python + tkinter, реализованное по
объектной модели из лабораторной работы №1 (диаграммы классов, состояний интерфейса,
макеты окон).

## Запуск

Нужен Python 3.9 или новее. Сторонние библиотеки не требуются (tkinter входит в Python;
на Linux, если его нет: `sudo apt install python3-tk`).

```
python main.py
```

При первом запуске создаются тестовые данные (папка `data/`):

| Роль         | Логин (email)           | Пароль       |
|--------------|-------------------------|--------------|
| Организатор  | teacher@example.com     | teacher123   |
| Участник     | student@example.com     | student123   |
| Участник     | partner@example.com     | partner123   |

В логин можно вводить и email, и имя. Чтобы начать с чистого листа, удалите папку `data/`.

## Как посмотреть все окна

1. **Один человек.** Войти как преподаватель → «Создать мероприятие» → сохранить →
   «Открыть конференцию» → написать в чат, нажать «Микрофон», «Экран», «Участники» →
   «Завершить» → экран статистики → «Скачать отчет» → на главной нажать «Запись».
2. **Два человека одновременно.** Запустить `python main.py` два раза (два окна).
   В первом войти как преподаватель и открыть «Созвон с командой» (у него включён зал
   ожидания), во втором войти как студент и нажать «Подключиться». Студент окажется в зале
   ожидания; преподаватель нажимает «Участники» → «Пустить» → «Дать микрофон».
   Окна обмениваются данными через файл `data/storage.pkl` и обновляются раз в 2 секунды.
3. Роль нового пользователя меняется командой
   `python tools/set_role.py email@example.com Организатор` (в макете регистрации поля роли нет).

## Тесты логики

```
python -m unittest discover -s tests -t .
```

## Структура проекта

```
main.py                    точка входа
app/
  injector.py              Инжектор: создаёт объекты и передаёт зависимости
  model/                   пакет «Модель»: Пользователь, Организатор, Участник, Мероприятие,
                           Файл, Статистика, Приглашение, СессияСвязи, УчастникСессии,
                           СообщениеЧата, ЗаписьВстречи (+ Репозиторий)
  controllers/             пакет «Контроллеры»: КонтроллерПользователей, КонтроллерМероприятий,
                           КонтроллерСессии, КонтроллерХранения
  views/                   пакет «Представление»: IПредставление, ИнтерфейсОрганизатора,
                           ИнтерфейсУчастника, ОкноПриложения, экраны (screens.py)
  extensions/              три направления развития (каркас без логики)
tools/set_role.py          смена роли пользователя
tests/                     модульные тесты
```

Имена классов, методов и атрибутов совпадают с диаграммами. Места, где пришлось
отойти от модели, помечены в коде комментариями `[отклонение Дn]` и описаны в отчёте.
